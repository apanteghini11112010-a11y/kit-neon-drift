# Neon Drift

Pagina statica in italiano per presentare un videogioco arcade immaginario.

## Avvio

Apri `index.html` in un browser. Non servono installazioni o JavaScript.

## File del progetto

- `index.html`: contenuti della pagina e riferimenti agli asset.
- `style.css`: foglio di stile della pagina.
- `pista.svg` e `auto.svg`: illustrazioni vettoriali originali per il progetto.
